# The Majestic: website

A portfolio concept site for a fictional boutique luxury real estate agency in India. Eight fictional residences, six page types, working filters, maps, a valuation calculator, a shortlist, validated enquiry forms and an AI concierge. It is plain HTML, CSS and JavaScript modules, with no build step.

Everything on it is fictional: the houses, prices, people, phone numbers and addresses. The pages carry `noindex` and a "Concept site" credit in the footer.

## Preview locally

```sh
cd the-majestic
python3 -m http.server 8766
# open http://localhost:8766
```

Open it through a server, not by double-clicking `index.html`: browsers don't run JavaScript modules from `file://`.

A local server has no `/api/concierge`, so the concierge answers with its built-in matcher. The label in the panel says **Concierge · smart match**. See [The AI concierge](#the-ai-concierge) to switch on the AI version.

| Page | File | What's on it |
|---|---|---|
| Home | `index.html` | Wordmark hero with search, (The House) with counters, the featured slider, the pinned (Destinations) chapter, (Our way), the concierge chapter, a valuation teaser, the FAQ with the closing curtain, and the enquiry form |
| Residences | `residences.html` | Filters kept in the address bar, editorial rows, list or map (a split view on wide screens) |
| Residence | `residence.html?id=<id>` | One template for every residence: gallery and lightbox, facts, story, highlights, specifications, locality map, adviser, enquiry form, similar residences |
| Valuation | `valuation.html` | The calculator, its breakdown, and a private valuation request it can prefill |

| Not found | `404.html` | Served by the host for any missing address |

## Where things live

```
css/styles.css             all styles: tokens → base → components → layout → pages → motion
js/boot.js                 runs first; turns motion on unless the visitor prefers reduced motion
js/main.js                 every page: header, menu, shortlist hearts, concierge, photos, motion
js/motion.js               the GSAP choreography (skipped entirely under reduced motion)
js/pages/*.js              one script per page
js/lib/                    formatting, filters, forms, maps, slider, valuation maths, concierge
js/data/properties.js      the eight residences: edit copy, prices and facts here
js/data/agents.js          advisers and offices
js/data/localities.js      base rates for the valuation calculator
js/data/photos.js          generated by the photo script; don't edit by hand
api/concierge.js           the AI concierge (a Vercel function)
tools/                     photo and placeholder scripts
tests/run.mjs              unit checks for the maths, filters and concierge matcher
```

The page header and footer are repeated in each HTML file. If you change one (a nav link, a phone number), change it in all seven.

## Adding your photos

Until photos arrive, every image is a dark tonal placeholder with its slot name written in the middle.

1. Name each photo after its slot, for example `home-hero.jpg` or `saal-villa-3.png`. JPG, PNG, HEIC, WebP and TIFF all work.
2. Put the photos in `the-majestic/photos/`.
3. From inside `the-majestic/`, run `sh tools/process-photos.sh` (macOS; AVIF needs macOS 13 or later).

The script saves each photo at 800, 1600 and 2400 pixels wide, as JPEG plus a smaller AVIF copy. It never upscales, so send the largest originals you have. It then updates `js/data/photos.js`, and the site swaps those placeholders for the real photos with no other changes. Slots without a photo keep their placeholder.

The site is dark, so photos taken at dusk or in the evening, with a warm interior glow, suit it best.

| Slot | Where it appears | What works best |
|---|---|---|
| `home-hero` | Full-screen behind the MAJESTIC wordmark | **Landscape, 2400px or wider.** Keep the bottom third dark or quiet: the wordmark sits there. |
| `home-house` | (The House), beside the counters | Portrait (4:5): an interior detail in lamplight |
| `destination-coast`, `-heritage`, `-hills`, `-city` | The pinned Destinations chapter, full screen | Landscape. Text sits on the lower left, so keep that area calm. |
| `principles` | (Our way), a tall image beside the five principles | Portrait (3:4) |
| `concierge` | The concierge chapter, with a sample chat card over its lower half | Portrait (4:5) |
| `valuation-hero`, `agency-hero` | The banner at the top of those pages | Landscape; the title sits bottom left |
| `<residence>-1` | The residence's main photo: rows, slider, cards, the map pop-up | **The exterior or an establishing shot**, landscape |
| `<residence>-2` … `-5` | The residence's gallery | Interiors and details, landscape, at least 1600px wide |
| `adviser-1` … `-3` | Adviser portraits (Meher, Arjun, Tara) | Portrait (4:5), face in the upper half |

The residence ids are `saal-villa`, `casa-azulejo`, `malabar-residence`, `amaltas-house`, `jharokha-haveli`, `cardamom-hill-estate`, `deodar-house` and `the-lavelle`. Each photo's alt text is in `js/data/properties.js` (the `images` list) and describes the photo the slot asks for. If your photo shows something else, update its `alt`.

To regenerate the placeholders (after adding a residence, say): `node tools/make-placeholders.mjs`.

## The AI concierge

The concierge works in two modes, and the panel shows which one replied:

- **Concierge · AI**: the page sends the conversation to `/api/concierge`. That function asks Claude, which recommends from the eight residences only, with a reason for each.
- **Concierge · smart match**: the built-in matcher in `js/lib/concierge-engine.js`. It reads budgets ("under 20 crore", "₹30 Cr"), places, bedrooms, family size and lifestyle words. It's used whenever the AI isn't available: no key, an error, or no answer within 8 seconds.

To switch on the AI mode on Netlify:

1. In the site's settings, under **Environment variables**, add `ANTHROPIC_API_KEY` with your Anthropic API key.
2. Redeploy.

The key stays on the server and never reaches the browser. The function calls Claude Opus 5.5 at low effort, to keep replies quick. You can change this with the optional variables `CONCIERGE_MODEL` and `CONCIERGE_EFFORT`. If a safety check declines a request, Anthropic's recommended fallback model answers instead (server-side fallback). Each message costs a fraction of a cent, but a public site can receive a lot of them, so set a spending limit in the Anthropic Console.

## Tests

```sh
node tests/run.mjs
```

This checks the valuation maths against hand-worked figures, the filters and their address-bar round trip, number formatting, Indian mobile number validation, and the concierge matcher against about 20 requests.

## Deploying

The site is set up for Netlify:

- `netlify.toml` runs `tools/build.sh`, which copies only the site's own files (the pages, `css/`, `js/`, `images/` and `_headers`) into `dist/`, and Netlify publishes that folder. Your source photos, the AI image backup, `tools/`, `tests/` and this README are never published.
- `_headers` sets the security headers, including a Content Security Policy. It allows only this site, cdnjs (GSAP and Leaflet), Google Fonts and Esri's map tiles.
- `netlify/functions/concierge.mjs` serves the AI concierge at `/api/concierge`, reusing the code in `api/concierge.js`.

Deploy from a Git repository or with the Netlify CLI so the function is included. A drag-and-drop deploy (run `sh tools/build.sh`, then drop `dist/`) also works, but drag-and-drop doesn't deploy functions, so the concierge then runs in smart-match mode.

The site still works on Vercel too: `vercel.json`, `.vercelignore` and `api/concierge.js` are kept for that.

## Before using it for a real agency

- Replace the residences, people, prices and contact details in `js/data/`, and the phone numbers and email addresses in the HTML.
- Connect the three forms to a real inbox or CRM. They validate and thank the visitor, but nothing is sent (`js/lib/forms.js`, `initForm`).
- Remove `noindex`, the "Concept site" footer line and the line under each form's button.
- The valuation rates in `js/data/localities.js` are invented. Replace them with real figures, or present the calculator as illustrative only.
- Point `og:image` at a full URL once the site has a domain.
